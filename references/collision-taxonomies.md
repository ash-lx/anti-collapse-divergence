# Collision Taxonomies

Use these taxonomies to nominate comparisons. They are **not** frame menus or automatic duplicate verdicts. A broad family can contain distinct causal paths. Compare the closest frames, then repair confirmed duplicates or preserve deliberate variants.

## Universal collision signs

Inspect frames that share several of these:

- actor class
- trigger moment
- carrier artifact / workflow
- pressure or incentive
- reinforcing loop
- failure condition

Different metaphors do not create real breadth if the causal path stays the same. Conversely, shared actors, artifacts, or settings do not erase a decisive difference in dependency, progression, or consequence. A family heading such as “external shock” is too broad to establish sameness on its own.

| Certification / attestation | badge, proof, stamp, audit, notarization, score, credential all doing the same trust-transfer job |

| Artifact contagion | screenshots, reports, verdicts, memes, share cards all spreading the same artifact |
| Professional standard | education, guild, open-source, curriculum, certification all becoming vocabulary capture |
| Anxiety / relief loop | habit, hospitality, risk, self-check all driven by private fear or relief |
| Enemy / movement | political, union, military, activism all built around enemy creation or power contest |
| Scarcity / prestige | luxury and status collapse into exclusivity / high-rank signaling |
| Marketplace sorting | dating, hiring, vendor choice, credentialing all reducing quality uncertainty |
| Workflow infection | file, API, memo, PR, ticket, dashboard carries use inside existing work |

## Analytics / causal clusters

| Cluster | Signs of collapse |
|---|---|
| Segmentation slice | cohort, plan, geography, device, persona all divide without causal mechanism |
| Funnel leakage | activation, conversion, step drop-off all explain by process friction |
| Expectation mismatch | promise gap, onboarding surprise, sales misfit, positioning drift all create expectation debt |
| Trust decay | reliability issues, silent failures, support delays, pricing surprises all erode confidence |
| Buyer/user split | economic buyer and daily user have different incentives |
| Novelty curve | honeymoon decay, feature fatigue, attention exhaustion all fade over time |
| External shock | seasonality, competitor, regulation, budget cycle all originate outside product behavior |
| Instrumentation artifact | metric definition, event tracking, data lag, pipeline change causes apparent shift |

## Research / theory clusters

| Cluster | Signs of collapse |
|---|---|
| Topic bucket | adoption, benefits, risks, productivity as descriptive buckets without mechanism |
| Framework trilogy | three dimensions with weak causal relations |
| Unit-of-analysis shift | same contribution achieved by changing level: individual, episode, practice, field |
| Boundary redefinition | role, category, jurisdiction, accountability boundary all doing same analytic move |
| Agency relocation | productive, epistemic, authorizing, artifact agency all explain who/what acts |
| Legitimacy transfer | authority, credibility, warranting, endorsement all explain acceptance of claims |
| Temporal reordering | acceleration, sequencing, path dependency, cadence all explain timing changes |
| Method caveat | “needs empirical validation” repeated as a generic future research escape hatch |
