Use anti-collapse divergence.

Task: Explore divergent frames for [TARGET].
Domain: [GTM/content/coding/analytics/research/product/ops/creative].
Constraints: [CONSTRAINTS].
Mode: [compact/standard/wide/weird/repair].

Rules:
- Generate mechanisms before tactics. Mechanism = what makes the idea work or fail: actor -> trigger -> carrier/artifact -> pressure/vector -> loop or failure condition. In creative work, compare action, form, and experience at the task's level.
- Ban obvious bubbles, name likely model attractors, then transform them. Use fresh source worlds; avoid each world's cliché mapping.
- Compare closest pairs: different names do not establish breadth, and three shared fields do not prove duplication. Look for the decisive causal dependency or progression. Mark insufficiently specified differences unresolved.
- When a practical mechanism is unclear, trace one ordinary instance and expose a material missing resource, permission, access, capacity, or handoff. Mention shared dependencies once. Skip extra grounding when the idea is already concrete; do not add generic acting/editing/production requirements to fiction.
- A checker flag requires semantic review, not automatic repair; a clean result does not certify distinctness.
- Use a fresh-context judge for Standard/Wide/Weird/Repair when available. Supply one set with stable IDs, without generation rationale. Check the judge's cited excerpts against the actual frames before accepting repairs.
- Report the process actually used: reviewed: fresh-context judge / provisional: tool-assisted self-audit / provisional: self-audit only. Tool-assisted requires a comparison tool to return results for this set; file reads/writes do not count. No status verifies creativity.
- Use cluster reasoning and an ordinal spread verdict: strong / usable / weak / collapsed. No 0-100 semantic-spread score.
- Repair confirmed duplicates before selecting top picks. Change the mechanism, not a quota of field labels. Recheck the final set; earlier review does not cover replacements.
- If missing context would change the mechanism space, ask one focused clarification with a recommended default.

Output: brief scope, banned bubbles/attractors, source worlds, frames, collision check, repairs if needed, and landing only if requested. Respect the user's count and format. Compact can use short prose and a closest-pair note; larger runs need a collision table. Avoid turning the workflow into repetitive per-idea paperwork.
